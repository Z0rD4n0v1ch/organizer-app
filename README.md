# Органайзер монтажника для Android

Приложение для телефона: задачи, объекты, рабочий автомобиль и заметки. Работает без интернета, все данные хранятся в телефоне.

## Как получить APK

1. Зайдите на github.com, нажмите «+» вверху справа → **New repository**. Название, например, `organizer-app`, можно сделать Private. Нажмите **Create repository**.
2. На странице нового репозитория нажмите ссылку **uploading an existing file**.
3. Распакуйте архив на компьютере, откройте папку `organizer-app` и перетащите **всё её содержимое** (папки `.github`, `app` и остальные файлы) в окно браузера. Нажмите **Commit changes**.
4. Откройте вкладку **Actions**: там запустится «Сборка APK». Через 3–5 минут появится зелёная галочка.
5. Откройте на телефоне страницу репозитория → справа раздел **Releases** → `latest` → скачайте `organizer.apk`. Для приватного репозитория войдите в GitHub в браузере телефона.
6. Откройте скачанный файл и разрешите установку из этого источника, если телефон спросит.

## Обновления

Когда загружаете новую версию файлов в репозиторий, APK собирается заново. Новый APK устанавливается поверх старого, данные сохраняются (приложение подписано одним и тем же ключом `app/organizer.keystore`, не удаляйте его).

## Резервная копия

Внизу вкладки «Сегодня» есть кнопки «Сохранить копию данных» и «Восстановить из копии». Сохраняйте копию, например, на Яндекс Диск: если телефон потеряется или приложение удалится, данные можно будет вернуть.
