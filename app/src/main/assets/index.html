                                                      Telegram-бот
                                                      
    
    
                                                      Без настройки записи пробега отправляются через «Поделиться»: выберите Telegram и чат бота. Чтобы отправлять в один тап, укажите бота: создайте его у @BotFather и вставьте токен. Затем напишите боту /start (или добавьте его в группу и отправьте любое сообщение) и нажмите «Найти чат».
                                                      
    
    
                                                      
    
                                                      Если Telegram заблокирован у провайдера
      
                                                      Отправка ботом идёт напрямую на сервер api.telegram.org. Если он недоступен, включите на телефоне VPN для всего устройства (или добавьте Органайзер в приложения VPN) либо укажите адрес своего прокси-сервера Bot API. Способ через «Поделиться» работает всегда, пока работает приложение Telegram.
