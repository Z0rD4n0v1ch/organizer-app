# Сервер бригады (прототип)

Сервер синхронизации общих объектов для «Органайзера монтажника» на [PocketBase](https://pocketbase.io) (один файл, без отдельной базы данных).

> Ветка `brigade-sync`, в релизы не входит.

## Что делает
- Бригадир создаёт бригаду, монтажники вступают по коду приглашения (без паролей, телефон получает токен на год).
- Объекты выкладывает бригадир и назначает на них людей. Монтажник видит только назначенные объекты.
- Изменения из телефонов сливаются: записи (задачи, оборудование, материалы, ТО, фото, документы) — по времени правки, карточка объекта — по полям.
- Сняли с объекта или убрали из бригады — объект удаляется с телефона при следующей синхронизации, токен убранного перестаёт работать.
- Фото и PDF хранятся на сервере и скачиваются телефонами по требованию.
- Всё закрыто от прямого доступа: работа только через `/api/brig/*` (`pb_hooks/brig.pb.js`).

## Запуск для проверки
```
./pocketbase serve --http=0.0.0.0:8090 --migrationsDir=./pb_migrations --hooksDir=./pb_hooks
```
В приложении: Настройки → Бригада → адрес `http://<ip>:8090`.

## Для бригады (VPS в России)
1. VPS с Linux (1 ядро, 1 ГБ памяти достаточно), домен или поддомен на его IP.
2. Скачать PocketBase для linux_amd64 со страницы релизов, положить рядом папки `pb_migrations` и `pb_hooks` из этой ветки.
3. Запуск с HTTPS (сертификат Let's Encrypt получится сам):
   `./pocketbase serve brig.example.ru --migrationsDir=./pb_migrations --hooksDir=./pb_hooks`
4. Сделать службой systemd, чтобы сервер запускался сам; резервная копия — папка `pb_data`.
5. В приложении: адрес `https://brig.example.ru`.

## API
| Метод | Путь | Кто | Что |
|---|---|---|---|
| POST | /api/brig/create | все | `{brigade, name}` → бригадир, токен |
| POST | /api/brig/join | все | `{code, name}` → монтажник, токен |
| GET | /api/brig/me | участник | я, бригада (код — только бригадиру), участники |
| POST | /api/brig/push | участник | `{items:[{obj,kind,cid,data,upd,del}]}` |
| GET | /api/brig/pull?since=N&full=… | участник | изменения после N, список видимых объектов |
| POST | /api/brig/assign | бригадир | `{obj, members:[id]}` |
| POST | /api/brig/kick | бригадир | `{member}` |
| POST/GET | /api/brig/file | участник | фото/PDF объекта |
